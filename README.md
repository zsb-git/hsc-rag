# HSC Economics RAG Chat

A small local chat app that answers questions about one PDF chapter
("Topic 1: International Economic Integration") using retrieval-augmented
generation. Runs entirely on this machine except for the final answer, which
is generated by the Claude API.

## Setup

1. Activate the virtual environment (already created):
   ```bash
   source .venv/bin/activate
   ```
2. Dependencies are already installed. To reinstall from scratch:
   ```bash
   pip install -r requirements.txt
   ```
3. Create an API key at [console.anthropic.com](https://console.anthropic.com),
   add prepaid credit, then copy `.env.example` to `.env` and fill it in:
   ```bash
   cp .env.example .env
   # edit .env, set ANTHROPIC_API_KEY=sk-ant-...
   ```

There are two ways to get the PDF into the vector database — pick whichever fits:

**Option A — local script** (for running only on this Mac): put the PDF at
`data/source_pdfs/Topic 1 International Economic Integration.pdf`, then run
`python ingest.py` once.

**Option B — upload through the app itself** (used automatically on Streamlit
Cloud, since the PDF is never committed to the repo — this is a public repo,
so the textbook content intentionally stays out of git): just launch the app;
if no data has been indexed yet, it shows a file-upload box. Upload the PDF
there and it gets chunked/embedded on the spot.

## Run locally

```bash
source .venv/bin/activate

# Optional: build the vector database from a local PDF file (Option A above)
python ingest.py

# Sanity-check retrieval before spending any API tokens (no cost)
python scripts/smoke_test.py "What is a trade bloc?"

# Launch the chat app (shows an upload box if nothing's indexed yet)
streamlit run app.py
```

The app opens at `http://localhost:8501`.

## Deploy to Streamlit Community Cloud (free)

1. Push this repo to GitHub (already done).
2. At [share.streamlit.io](https://share.streamlit.io), create a new app pointing at
   this repo, branch `main`, main file `app.py`.
3. In the app's **Settings → Secrets**, add:
   ```toml
   ANTHROPIC_API_KEY = "sk-ant-..."
   ```
4. Deploy. On first load it'll show the upload box — upload the PDF there
   (it's never stored in git; the vector DB lives only on that running instance's
   disk, which resets on redeploys, so it needs re-uploading after any
   code push or long sleep/wake cycle).

## Cost

- Vector DB (Chroma) and embeddings (local `sentence-transformers` model): **$0**, run entirely on this machine.
- Answers (Claude Haiku 5.5 via the Anthropic API): pay-per-use, roughly $0.10/million input tokens and $0.50/million output tokens. A typical question costs a small fraction of a cent.
