# HSC Economics RAG Chat

A small local chat app that answers questions about one PDF chapter
("Topic 1: International Economic Integration") using retrieval-augmented
generation. Runs entirely on this machine except for the final answer, which
is generated by the Claude API.

## Setup

1. Activate the virtual environment (already created):
   ```bash
   source .venv/bin/activate
   ```
2. Dependencies are already installed. To reinstall from scratch:
   ```bash
   pip install -r requirements.txt
   ```
3. Create an API key at [console.anthropic.com](https://console.anthropic.com),
   add prepaid credit, then copy `.env.example` to `.env` and fill it in:
   ```bash
   cp .env.example .env
   # edit .env, set ANTHROPIC_API_KEY=sk-ant-...
   ```
4. Put the source PDF at `data/source_pdfs/Topic 1 International Economic Integration.pdf`.

## Run

```bash
source .venv/bin/activate

# 1. Build the vector database from the PDF (run once, or again after changing the PDF)
python ingest.py

# 2. Sanity-check retrieval before spending any API tokens (no cost)
python scripts/smoke_test.py "What is a trade bloc?"

# 3. Launch the chat app
streamlit run app.py
```

The app opens at `http://localhost:8501`.

## Cost

- Vector DB (Chroma) and embeddings (local `sentence-transformers` model): **$0**, run entirely on this machine.
- Answers (Claude Haiku 5.5 via the Anthropic API): pay-per-use, roughly $0.10/million input tokens and $0.50/million output tokens. A typical question costs a small fraction of a cent.
